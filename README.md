## About ROE

**ROE Office** is an open-source office software project built from the ground up with Rust.

Our goal is to create a modern, native office engine with a unified architecture for document processing, spreadsheets, and presentations.

Designed with Linux as a first-class platform, ROE aims to deliver a lightweight, modular, and extensible office experience.

## Our Products

| Product | Description |
|---|---|
| **ROE Writer** | Word processing and document editing |
| **ROE Calc** | Spreadsheet calculation and data analysis |
| **ROE Impress** | Presentation creation and editing |

Three applications. One unified engine.

## Technology

- **Rust-native architecture** — performance, safety, and reliability.
- **Headless core engine** — independent of any particular graphical interface.
- **ODF-native document model** — built around an open document architecture.
- **OOXML compatibility** — support for interoperability with Microsoft Office formats.
- **Modular design** — designed for multiple frontends and extensible integrations.

## Our Philosophy

We believe office software should be open, efficient, and accessible.

ROE is built with a focus on native Linux applications, open standards, and a clean separation between the document engine and user interface.
